## Interpretation

This benchmark is generated by `scripts/run_held_out_benchmark.py` using seed `20260827`. Running the documented command regenerates the canonical `evaluation/final_benchmark/` dataset and machine-readable `outputs/metrics.json` / `outputs/metrics.csv` metrics. The reconciliation engine, confidence scoring, thresholds, ground truth construction, and evaluation formulas are not changed for the benchmark.

The held-out data is synthetic and should not be interpreted as production accuracy. The engine deliberately favors precision over recall: uncertain cases are sent to REVIEW/UNMATCHED rather than silently auto-matched.

The ambiguous scenario's distractor payments are explicitly represented as `unmatched_payment` ground-truth rows so the auxiliary unmatched-payment metric does not silently omit them.
